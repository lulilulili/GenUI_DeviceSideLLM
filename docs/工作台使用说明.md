# GenUI 本地工作台

启动：在工程根目录运行 `python -m genui_intent.workbench`，打开 http://127.0.0.1:8765。

页面提供后端选择、API 基础地址、模型名称、Key、超时、输出约束和用户提示词。Ollama 地址通常是 http://127.0.0.1:11434；兼容 API 地址须截止到 /v1 等基础路径，适配器追加 /chat/completions。外部接口使用 HTTPS。外部请求会发送提示词和候选，不发送项目文件。

点击运行后观察阶段时间线；点击阶段可查看真实输入、原始响应或扩展后的 JSON、错误、耗时和服务端 token 用量。运行中的模型节点会亮起；当前响应按整次调用返回，不是逐 token 展示。导出事件 JSON 可留档，包含提示词但不包含配置中的 Key。

架构说明是可离线阅读的 `web/architecture.html`，同一服务的 /architecture 路径可以打开。图示区分当前意图链路与规划中的实体、能力、内容、布局模块。

可扩展接口：`Trace.stage(stage_id, inputs)`。阶段自动发布 running/completed/failed；输出写入 event["output"]，异常自动记录。事件版本 1.0，包含 runId、sequence、timestamp、elapsedMs；模型调用另含 usage。运行总耗时独立统计，避免父子阶段重复计时。

仅支持 Ollama、Chat Completions-compatible 和固定 Mock。厂商 Responses 或其他专用协议需要新的 Provider。缺少服务端 usage 时显示未知，不使用字符数冒充 token。API Key 不持久化；服务仅监听回环地址，不用于公网生产部署。
