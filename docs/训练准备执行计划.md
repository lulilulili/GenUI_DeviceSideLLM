# 模型训练准备 · 执行计划

> 使用方式：按序执行，每步完成后带着「向我汇报」栏的内容回来交流，我基于结果给下一步的具体参数。
> 两个决策点（A/B）必须停下对齐后再继续。标 ⚡ 的步骤可并行。

## 阶段 1 · 评测地基（≈1 周，先于一切训练）

| # | 步骤 | 动作要点 | 产出物 | 完成标准 | 向我汇报 |
|---|---|---|---|---|---|
| 1.1 | 冻结测试集 v1 | 300~500 条，分 8 桶：单域明确字段 / 只提领域不提字段 / 近义词长尾 / 否定与纠正 / 跨域混合 / 不支持请求 / 多动作 / 字段外需求。人工写 + 大模型扩写后**逐条人审**。每条标注期望：领域、语素集合（键+角色）、或应拒绝 | frozen_set_v1.jsonl | 分桶数量达标；任何条目不进训练集 | 分桶统计表 + 每桶 2 条样例 |
| 1.2 ⚡ | 评测 harness | 脚本：读测试集→调管线→自动评分。指标：领域准确率、字段选择 P/R/F1、角色准确率、绑定 EXACT 率、一次通过率、端到端出卡率；"通过但语义偏"抽 10% 人审 | eval/run_frozen_eval.py | mock provider 上跑通，输出 JSON 报告 | 报告格式样例 |
| 1.3 | 裸模型基线 | qwen2.5:3b 与 qwen2.5:1.5b 各跑一遍冻结集（temperature=0，与生产同款约束解码） | baseline 报告 ×2 | 两组完整分数 | **两组分数 → 决策点 A** |

**决策点 A（拿 1.3 结果来）**：语素语义 F1 ≥85% → 训练缓行，优先做厚注册表/变体；70~85% → 走 LoRA（阶段 2-3）；<70% → 先与我重审任务切分或考虑 4B，再决定是否造数据。

## 阶段 3 · 训练与验收（≈1 周）

| # | 步骤 | 动作要点 | 产出物 | 完成标准 | 向我汇报 |
|---|---|---|---|---|---|
| 3.1 | LoRA SFT | qwen2.5-3b（决策 A 若倾向 1.5b 则两个都训），rank 8~16，attn+MLP，2~3 epoch，few-shot 保留在样本内 | adapter 权重 | val loss 收敛无过拟合 | 训练曲线 + val 指标 |
| 3.2 | 冻结集复测 | 训后模型跑 1.2 harness，与基线同表对比 | 对比报告 | 一次通过率与 F1 提升可见 | **基线 vs 训后对照表 → 决策点 B** |
| 3.3 | 量化验收 | 合并导出 GGUF Q4_K_M，进 Ollama（Modelfile），**量化版再跑冻结集** | 量化模型 + 报告 | 量化回退 ≤3pt | 量化前后分数差 |

**决策点 B（拿 3.2/3.3 结果来）**：达标 → 阶段 4；一次通过率仍低但 F1 高 → 用 2.2 偏好对做 DPO 一轮再测；整体不达标 → 带错误分析回来，我们定位是数据分布还是任务切分问题。
