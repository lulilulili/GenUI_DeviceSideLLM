DRAFT ITEM

每个 Morpheme 的字段

短字段完整含义类型规则
ktype组件枚举描述数据适合的交互与视觉形态。
rrole角色枚举决定视觉中心、区域分配和裁剪优先级。
llabelstring / null用户可见标签，建议不超过30字。
qsemanticKey开放英文字符串说明数据或操作语义，如 weather.temperature；不是实际 API。
fvalueType数据类型枚举连接 Mock 数据、格式化和组件一致性校验。

模型不生成 id、priority、actionKey、Mock 数值、坐标或 CSS；这些由后续代码补齐。

TYPE ENUM

8 类基础组件

TEXT · 文字

段落、摘要、说明和无法进一步结构化的文本。通常搭配 STRING。

“显示会议结论”

METRIC · 指标

突出单个数值、百分比、时间或时长。紧凑卡片中的百分比也可降级为 Metric。

24°C / 68% / 25分钟

STATUS · 状态

只读枚举或布尔状态，不提供修改能力。

晴 / 已连接 / 运行中

PROGRESS · 进度

比例、完成度、容量和剩余量，标准视觉成本为2。

电量68% / 完成率72%

SWITCH · 开关

明确的二态操作。只有用户要求可切换时使用，不能替代只读状态。

蓝牙 / 灯光电源

SLIDER · 连续调节

连续或分级数值控制，标准视觉成本为2。

亮度 / 音量 / 温度调节

BUTTON · 触发动作

点击后触发一次操作，不承载持续状态。

刷新 / 开始计时 / 查看详情

LIST · 同类列表

多条结构相近的数据，视觉成本为4；小卡片中容易被裁剪或紧凑化。

今日待办 / 天气预报
ROLE ENUM

语义角色与默认优先级

取值默认优先级布局含义
WARNING100异常和风险，最优先保留。

PRIMARY_ACTION85主要操作，进入 actions 区域。
SECONDARY60辅助状态或指标。

INFORMATION BUDGET

尺寸控制的是布局成本，不只是数量

尺寸最大语素预算推荐内容
2x133核心状态和2～3个轻量指标
2x268核心信息、辅助指标和少量操作
3x2811横向服务、快捷入口、媒体控制和图表
3x3814较完整数据、列表和多个操作
AUTO812根据内容自动决定

TEXT、METRIC、STATUS、SWITCH、BUTTON 成本为1；PROGRESS 和 SLIDER 为2；LIST 为4。2×1 中的次级 PROGRESS 可降级为紧凑 METRIC，以保留信息而不是直接删除。

PROMPT EXAMPLES

推荐用户表达

公式：生成一张［主题］卡片，分别展示［数据］，提供［操作］，重点突出［核心内容］。

天气

生成一张上海天气卡片，分别展示今天的天气状况、气温和湿度，重点突出气温。

设备

生成一张耳机状态卡片，重点展示剩余电量，同时展示连接状态，并提供蓝牙开关。

控制

生成一张客厅灯光控制卡片，展示当前亮度和开关状态，提供灯光开关和亮度调节。

任务

生成一张今日待办卡片，列出今天的任务和完成状态，重点突出完成进度。
